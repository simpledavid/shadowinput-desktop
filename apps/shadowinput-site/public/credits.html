素材与致谢

感谢这些开放的创作。

shadowinput 基于 Arion 开发，以 AGPL-3.0 协议开源。官网的视觉设计参考 Arion 官网，并针对中文内容与键盘写作场景重新制作。这里保留所用素材的出处与许可说明。

背景图片

银杏枝叶、水面光影与纸张纹理均通过 AI 图像工具为 shadowinput 独立生成。本版不再使用 Arion 官网的花卉摄影文件。

  • 银杏枝叶：用于首屏与个人风格示意。
  • 水面光影：用于选区修改示意。
  • 纸张纹理：用于修改审阅示意。

图标与标识

GitHub 和 OpenAI 标识沿用 Arion 的图标资产。OpenAI 标识来自 LobeHub Icons（MIT），其余保留上游图标许可。查看 LobeHub 许可 与 上游图标声明。标识仅用于说明相应服务，不表示这些服务为 shadowinput 背书。

代码与产品示意

桌面应用源码与协议见 shadowinput-desktop。页面中的写作、选区、审阅和风格卡画面是为说明功能制作的网页示意，并非桌面应用截图；交互示例使用预置文案，不会调用模型。
