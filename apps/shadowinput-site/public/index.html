功能示意
01 / 在输入的位置

选中就改，
不用换个窗口。

写消息、回邮件，选中想修改的那一段。快捷键唤起小浮窗，生成后检查，再应用回原处。

遇到不支持的输入框，也可以粘贴原文、复制结果。

⌘+⇧+J
02 / 修改看得见

改了什么，
先看清楚。

用增删对比展示每一次修改。数字、日期、词表和承诺出现可疑变化时，提示你复核后再用。

检查是辅助，不能保证原意完全不变。特别是续写，最终决定仍在你手里。

03 / 个人表达习惯

少一点套话，
多一点自己。

工作沟通简洁一点，邮件礼貌一点。编辑自己的风格卡，把人名、产品名放进专有词表，给不同操作设置默认偏好。

这些偏好保存在本机，可随时修改；不会自动读取你的聊天历史。

输入法：安装主程序后，在“输入法设置”安装组件，再从系统菜单切换到 shadowinput。本地模型在应用内另行下载；启用 AI 联想后，空格上屏，稍停，按 Tab 采纳短语。

Chrome 插件：先解压 ZIP，打开 chrome://extensions，开启“开发者模式”，选择“加载已解压的扩展程序”，再选择解压后的 shadowinput 文件夹。点击插件，使用 ChatGPT 继续。无需桌面端或 API Key；这不是商店一键安装版。

插件：代码与模拟页面测试通过；独立插件授权回调、真实 ChatGPT 翻译、Chrome 实装和网页兼容性仍待验证。桌面端登录成功不代表插件已通过。PDF、电子书、视频字幕和图片翻译尚未实现。

插件仅在操作翻译后发送文字；如果单独开启某网站的自动翻译，也会自动发送本站正文。凭据保存在当前 Chrome 配置中，不是系统钥匙串加密。每次网页翻译最多处理 120 段。
