# 011 Keyboard-first writing

This specification applies to the separate shadowinput entry point. The upstream voice entry point retains its existing behavior.

- WRT-01: Use native MyGo on macOS arm64 and Windows x64; retain AGPL and attribution.
- WRT-02: Read clipboard text only after explicit import; the shortcut reads only the selected range in a supported control; submit only after Generate. Source text is bounded to 64,000 UTF-8 bytes; additional instructions to 4,000 bytes. Invalid inputs make no model request.
- WRT-03: Support polish, translate, rewrite and full-draft continuation. Preserve source independently of previews. Changed source/task/model/instructions revoke delivery of prior output.
- WRT-04: Use official OSS ChatGPT registration with fresh PKCE/state/nonce, a stable host ID and issued client ID. Verify ID-token signature, issuer, audience, expiry, nonce and subject; require the plan-use grant before inference. Keep tokens outside UI state and encrypt persisted credentials with a separate OS-protected key.
- WRT-05: In ChatGPT mode, query account-specific models and stream Responses API requests. Only a nonempty `response.completed` result authorizes Copy/Paste. Errors, refusal, incomplete output, canceled jobs and late results cannot authorize delivery. Never replay an uncertain generation automatically.
- WRT-06: Paste only after an explicit click, native target checks and clipboard ownership verification. Consume the captured target and send once. Unknown delivery is never described as verified insertion. Closing cancels work and releases the target.
- WRT-07: Start no audio worker, background model download, upstream account, sync, usage reporting or updater. Keep normal text editing available without sign-in or Accessibility permission.
- WRT-08: Keep English/Simplified Chinese copy aligned and show actionable authentication, permission, quota, generation and clipboard errors.

- WRT-09: Invoke a native compact panel at the captured selection or pointer. Read only a nonempty selected range through macOS AX or Windows UIA; reject protected, unsupported and oversized selections. Do not silently substitute clipboard text. Preserve manual editing/import when capture is unavailable.
- WRT-10: Revalidate the external field, selected text and range immediately before applying. A changed or unavailable selection rejects delivery and leaves the generated result available for manual copying. No automatic reactivation or retry after an uncertain paste; no claim of atomic editor transactions or external undo.
- WRT-11: Show bounded Unicode-preserving additions/deletions and a plain-result toggle. Locally flag possible number, date, glossary-term and commitment changes. Require explicit acknowledgment before app Copy/Apply when flagged. These checks are advisory, may miss changes or flag equivalent formats, and do not guarantee semantic fidelity. Names are protected only when entered in the glossary.
- WRT-12: Store editable style cards, a personal glossary and per-operation defaults locally. Persist validated updates with temporary-file replacement; surface read/write failures without silently resetting corrupt profiles. Send only the selected style and terms present in the explicitly submitted draft. No automatic ChatGPT memory/history import.
- WRT-13: Show the active account and available model, explain authorized plan use, and link to official usage management without inventing remaining quota. Distinguish expired authorization, missing grants, unavailable model, quota and transport errors; preserve the draft and provide reauthorization/model-refresh/usage actions. Switching accounts clears account registration and credentials only after persistence succeeds, retaining device identity.

- WRT-14: Offer Local model and ChatGPT as explicit providers. New installations default to local; older saved ChatGPT preferences retain that choice. Local mode never opens the account vault, starts OAuth or falls back to cloud. Download the pinned Qwen3.5-2B Q4_K_M only after Download & start; verify the exact size and SHA-256 before loading. Subsequent Start model requires an installed model and makes no download. Show progress, cancel, stop and actionable failure states; serialize superseded setup operations and preserve the draft.
- WRT-15: Run local writing through the bundled worker and private native socket on macOS arm64 or Windows x64. Use the same writing task/style/glossary instructions and review gate as the cloud provider. Disable reasoning and prompt caching; erase the slot before and after each completion. Cancellation destroys private runtime state and reloads only for the next explicit request. Enforce the complete rendered 4096-token context and a maximum 2048-token response; reject over-budget or incomplete output without exposing a deliverable partial result. Local weights are not bundled in application downloads.

Acceptance is tracked in the [shadowinput project document](../docs/project/shadowinput.md). Unit or headless tests do not establish real account or OS acceptance.
